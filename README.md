# ExperienceOS

> 一个开源 AI 个人经历操作系统，帮助开发者记录、整理和沉淀自己参与过的所有项目与创造经历。

## 🌟 为什么做？

很多开发者并不是没有经历，而是：

- 做过很多项目，却随着时间逐渐遗忘
- GitHub 仓库越来越多，却不知道如何整理
- 面试时难以准确描述自己的贡献
- 毕业或跳槽时才开始临时整理项目经历

ExperienceOS 希望帮助每个人建立属于自己的长期经历档案。

它不是一个简单的简历生成工具，而是一个能够理解你的项目、记录你的成长、沉淀个人经验的 AI Agent。

---

## ✨ 核心能力

### 📁 项目经历收集

支持整理：

- 毕业设计
- 课程项目
- 竞赛项目
- 实习项目
- 工作项目
- 开源贡献
- 个人作品


### 🤖 AI 项目理解

通过分析：

- 项目文件
- README
- Git 历史
- 用户描述

帮助提取：

- 项目背景
- 用户角色
- 技术栈
- 核心贡献
- 技术挑战
- 项目成果


### 💬 AI 主动访谈

ExperienceOS 会主动询问：

> 你在这个项目中负责什么？

> 遇到过哪些技术挑战？

> 为什么采用这种方案？


帮助用户补充隐藏在记忆中的项目价值。
