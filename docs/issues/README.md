# Issue 拆分索引

本目录是 GitHub-ready 的 Issue 清单，按 Milestone 分组。创建仓库后可用
`gh issue create` 逐条导入（标题取 `Title:`，正文取正文），或先在本地评审。

约定：

- 每个 Issue 独立可交付、可验收（Acceptance Criteria 可勾选）。
- 标签：`area/core` `area/cli` `area/ai` `area/connector` `area/exporter`
  `area/docs` `area/infra`；难度：`good first issue` / `intermediate` /
  `advanced`。
- 优先级 P0（必须）> P1（应该）> P2（可以）。
